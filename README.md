⚡ Circuit Dash — Genesis Debug Challenge

Circuit Dash is an interactive C programming and debugging challenge designed to test logical thinking, problem-solving skills, and error detection. Participants analyze code, identify logical errors, debug faulty functions, and improve program behavior through hands-on challenges with varying difficulty levels.

The project focuses on core C programming concepts, including functions, loops, arrays, conditional statements, switch-case menus, input validation, and logical operations.

🎯 **Key Features**
- 🐛 Bug-hunting and code debugging challenges
- 🎚️ Multiple difficulty levels: Easy, Medium, and Extreme
- 💻 C programming logic and error detection
- 🧠 Problem-solving and analytical thinking
- 🏆 Designed for coding competitions, workshops, and technical events

**Tech Stack:** C, with a web-based interface planned for interactive challenges and deployment.

Built for aspiring programmers, debugging enthusiasts, and competitive coding events.

*Find the bug. Fix the logic. Win the challenge.*
